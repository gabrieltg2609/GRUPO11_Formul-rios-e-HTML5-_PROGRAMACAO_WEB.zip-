# Guia de estudo do CampusLab

1. Qual a diferença entre id e name? Localize ambos no campo nome. O id identifica o elemento e associa seu label; name identifica o dado enviado.
2. Por que telefone usa tel e vagas usa number? Telefone é identificador, vagas é quantidade.
3. Qual a diferença entre select e datalist? Select restringe às opções; datalist fornece sugestões.
4. O que acontece ao enviar campos obrigatórios vazios? O navegador impede o envio normal.
5. Por que step="1800" no horário? O intervalo é expresso em segundos: 30 minutos.
6. O que GET faz? Os pares nome/valor vão para a consulta da URL.
7. Por que a confirmação não comprova um cadastro? É uma página estática, acessível diretamente.
8. Por que existe CSS externo? As quatro páginas reutilizam apresentação e estados.
9. O que muda em 900px e 680px? Primeiro os campos passam a uma coluna; depois o painel vai abaixo do formulário.
10. Como testar teclado? Use Tab, Shift+Tab, espaço e setas, observando o foco.

Exercício: altere o máximo de vagas para 3 e teste 2, 3 e 4. Depois restaure 5.
Exercício: remova temporariamente name do campo curso e compare a URL de envio.
Exercício: explique um erro que vocês realmente encontraram e a correção aplicada.
